WhiteningLayer

可微分白化层 · 数学原理与 PyTorch 实现
? 它是什么？为什么需要它？

在 JEPA（Joint-Embedding Predictive Architecture）中，encoder 输出的隐变量 z 需要同时满足两个矛盾的要求：

  • 可预测：predictor 能准确预测下一帧的 z → MSE 损失小
  • 不坍缩：不同输入的 z 必须不同，不能都变成常数

原版 LeWM 用 SIGReg 来防止坍缩——它是一个统计检验损失，迫使 z 的分布接近各向同性高斯。但这是一个"事后惩罚"：先做，不符合就罚。

WhiteningLayer 则是一个架构层面的约束——在 encoder 输出后接一个可微分线性变换，数学上保证输出的协方差矩阵 = I。不需要任何损失项，防坍缩是天然的（因为坍缩会导致除以零而 NaN）。

Σ 数学原理

给定一批 encoder 输出的原始 embedding h1, ..., hN ∈ ℝD，白化层计算：

Step 1: 去均值 hc = h − μ     其中 μ = 1/N Σi hi
Step 2: 计算协方差矩阵 Σ = 1/(N−1) HcT Hc   ∈ ℝD×D
Step 3: 对称特征分解 Σ = V Λ VT     其中 V = 特征向量（正交矩阵，VVT=I）， Λ = diag(λ1, ..., λD)
Step 4: 白化变换 z = hc · V · diag(1/√λi) · VT
验证输出性质： 可以证明 Cov[z] = V · Λ−1/2 · VT · Σ · V · Λ−1/2 · VT = I
即输出 z 的协方差矩阵是单位矩阵，任意两维不相关且方差为 1。
几何直观 白化变换的三个步骤
1
平移：减去均值 μ，把数据中心移到原点
2
旋转：VT 把坐标系旋转到主成分（特征向量）方向。此时数据在其各维度上不相关。
3
缩放：Λ−1/2 把每个主成分方向的方差缩放到 1（除以标准差）。然后 V 旋转回原始坐标。

初始化
# running_mean: initial 0 # running_cov: initial I self.register_buffer("running_mean", torch.zeros(dim)) self.register_buffer("running_cov", torch.eye(dim))

μ 和 Σ 存为 buffer（不是 parameter），不参与梯度计算。 初始化 running_cov = I → 训练开始前白化层等价于恒等映射。

_whiten(x, mean, cov, eps)
centered = x_f32 - mean_f32 eigvals, eigvecs = torch.linalg.eigh(cov) eigvals = eigvals.clamp(min=eps) transform = eigvecs * eigvals.rsqrt().unsqueeze(0) whitened = centered @ transform @ eigvecs.T

用 eigh（对称矩阵特征分解）代替 Cholesky，更稳定。
支持 B·T < D 的低秩情形（clamp 防止除零）。

Forward 逻辑：两种模式
def forward(self, x): if self.training and not self.frozen: # 训练态 unfrozen: 用 batch 统计量白化 + 更新 running 统计量 mean = x.mean(0, keepdim=True) cov = (centered.T @ centered) / (N - 1) self.running_mean = momentum * self.running_mean + (1-momentum) * mean self.running_cov = momentum * self.running_cov + (1-momentum) * cov return self._whiten(x, mean, cov, eps) else: # 推理态 / frozen: 用 running 统计量（永不更新） return self._whiten(x, self.running_mean, self.running_cov, eps)
⚡ 两种模式对比
Unfrozen（默认训练态） Frozen（冻结）
统计量来源 当前 batch 的 μ, Σ 预计算的 μ, Σ（不更新）
统计量更新 每步更新 running_mean/cov 永不更新
白化变换 每步不同（batch 变 → 变换变） 恒定不变
适用场景 从零训练（encoder 也在变化） 预训练模型 + 微调（固定白化空间）
稳定性 不稳定 batch 间波动 → 预测器目标准移 稳定 目标空间恒定
各向同性 退化 encoder 漂移后过时 保持 统计量始终有效
frozen 模式的触发条件：self.training and not self.frozen
调用 model.eval() 时 frozen=True。
即使在 model.train() 下，只要 frozen=True（在__init__中设置），就始终使用 running 统计量。 这使我们可以"预计算统计量 → 冻结 → 放进训练循环，白化变换不动"。

▸ 最小验证

用 NumPy 验证白化层的数学性质：

# 生成 1000 个随机点，故意构造非各向同性分布 h = np.random.randn(1000, 4) @ np.diag([5.0, 2.0, 0.5, 0.1]) # 白化 cov = np.cov(h, rowvar=False) eigvals, eigvecs = np.linalg.eigh(cov) z = (h - h.mean(0)) @ eigvecs @ np.diag(1.0 / np.sqrt(eigvals.clip(min=1e-4))) @ eigvecs.T # 验证：输出协方差 ≈ I cov_z = np.cov(z, rowvar=False) np.allclose(cov_z, np.eye(4), atol=1e-6) # → True
